# Kerith Landing

Landing page for Kerith, set up as a Vite application in the pnpm workspace.

## Stack

- Vite
- React and TypeScript
- Tailwind CSS
- ESLint

## Development

```bash
pnpm install       # Run once from the repository root
pnpm dev:landing   # Run from the repository root
```

## Build

```bash
pnpm build         # Build all workspace apps from the repository root
```
